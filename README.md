# FireThread
F360 formatted XML files for firefighting specific thread patterns (NH/NPSH/NPT/GHT)
These were mostly AI generated and have not been completely tested, but they tend to work well.

I have deliberately selected no license. 
As a Current Firefighter, it's important to me to share such things, that could result in technological improvements or life safety devices.
Therefore, please use them commercially to your heart's content.

Generated/collected by Grok/SpacexAI 2026.

thanks,

-Nick

HOW TO INSTALL/USE:

We highly reccomend the use of the extension for F360 called "Threadkeeper" Link Here: https://marketplace.autodesk.com/apps/450d1a56-d83b-4ddb-b637-35ef5d8f61fd
I have been using this for years personally and it has literally saved me months of having to move shit around in fusion's backend.
Install the extension, then open the threadkeeper directory. unzip the file, and move all .xml files into the threadkeeper folder. 
restart fusion and your threads should appear.

If you hate yourself and desire suffering, manual installation instructions are in the self-contained readme in the Zip file.
